# Library

## Updates

KuroToon checks your library for new chapters on the schedule in **Settings → Library → Automatic
updates**. Restrictions (Wi-Fi only, charging, skip completed titles, skip unread titles) keep updates
light on battery and data.

## Large bulk updates

Updating or downloading a lot of titles from one source at once can get you rate limited or blocked
by that website. KuroToon warns you before large bulk operations so you can split them up. Using
categories and updating one category at a time is the easiest way to keep each run small.

## Upcoming

**Updates → Upcoming** estimates when each title in your library will release its next chapter, based
on how often new chapters appeared in the past. It is a guess, not a schedule from the source.
