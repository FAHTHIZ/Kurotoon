# Storage

KuroToon asks for a storage folder the first time you open it. Downloads, automatic backups and local
source titles live inside that folder:

```
<your folder>/
├── autobackup/   automatic backups
├── downloads/    downloaded chapters, one folder per source and title
└── local/        your own files for the Local source
```

You can change the folder at any time in **Settings → Data and storage → Storage location**. Move the
existing files yourself if you want to keep them.

**Local source.** Put a folder per title in `local/`, with chapters as folders of images or as
`.zip`, `.cbz`, `.rar`, `.cbr`, `.7z`, `.cb7` or `.epub` files. Add a `cover.jpg` and an optional
`ComicInfo.xml` or `details.json` for metadata.
