# Try every feature

A walk through KuroToon as a new user would meet it, in about 20 minutes. Tick each box as you go. If a step
doesn't do what the "you should see" line says, [open an issue](https://github.com/FAHTHIZ/Kurotoon/issues) with the
step number and a screenshot.

## Before you start

1. Download the APK from the [latest release](https://github.com/FAHTHIZ/Kurotoon/releases/latest). Most phones want
   `arm64-v8a`; `universal` works on any phone. `checksums.txt` lets you verify the download.
2. Install it. KuroToon installs next to Mihon or Tachiyomi; it doesn't replace them.
3. Have one extension store URL ready (an `index.min.json` link), or a `tachiyomi://add-repo` link.

## 1. First run

- [ ] **1.1** Open the app. You should see the KuroToon logo, step dots and a Next button.
- [ ] **1.2** Pick a theme. The screen recolours straight away.
- [ ] **1.3** Storage: **Inside KuroToon** is already ticked, so Next works straight away. **A folder you pick** opens
  the system folder picker instead.
- [ ] **1.4** Grant or skip permissions. The last step offers **Add my first source**, **Restore a backup** and the
  guide; **Get started** lands you on **Home**, which shows a welcome card and an Add sources button.

## 2. Get some sources

- [ ] **2.1** Browse → Extensions → menu → Extension stores → Add, paste the store URL. Extensions appear as cards.
- [ ] **2.2** Tap **Install** on one. The pill shows progress, then the extension moves to Installed.
- [ ] **2.3** Browse → Sources. The new source is a card with **Popular** and **Latest** pills.
- [ ] **2.4** Tap Popular. Covers load in a grid; the genre and theme tags along the top filter in one tap.
- [ ] **2.5** Long-press a tag. It turns into an exclude filter.

## 3. Find and keep a series

- [ ] **3.1** Search from the Browse search bar. Each source gets an accent header, a See all pill and pulsing
  placeholders while it loads.
- [ ] **3.2** Open a result. The series page has a cover-tinted header, rounded action tiles and tag pills.
- [ ] **3.3** Tap **Add to library**. Pick a category if asked.
- [ ] **3.4** Menu → **Edit info**, change the title, save. Pull to refresh: your title stays.
- [ ] **3.5** Long-press a cover anywhere in Browse. It's added without opening the page.

## 4. Library

- [ ] **4.1** Open Library. The title has a count pill; categories are pills; Unread, Downloaded, Started and
  Bookmarked are one-tap filters.
- [ ] **4.2** Switch to list mode from the display sheet (its tabs are segmented pills). Entries become cards.
- [ ] **4.3** Menu → open a random entry. A series from the current category opens.

## 5. Read

- [ ] **5.1** Open chapter 1. Webtoons and manhwa open as a long strip, manga as pages.
- [ ] **5.2** Tap the middle. Controls float in a rounded dock; the page slider shows the current page.
- [ ] **5.3** Tap the music note. The sound sheet offers the soundtrack, ambience and a **sleep timer**. Start one;
  when it ends the music fades out.
- [ ] **5.4** Start **auto-scroll** and change its speed.
- [ ] **5.5** Long-press a page → **Keep panel**. It appears in **Your panels** on Home.
- [ ] **5.6** Leave mid-chapter, come back from Home's **Continue reading**. You return to the same panel.
- [ ] **5.7** Finish the chapter. A small celebration plays and the next chapter is one tap away.
- [ ] **5.8** Reader settings → **Data saver** and **Bedtime warmth** change the page right away.

## 6. Stay up to date

- [ ] **6.1** Updates tab → pull to refresh. A status card shows the last check; new chapters get NEW badges.
- [ ] **6.2** Open the release schedule from Updates. Series you follow sit on the days they usually update.
- [ ] **6.3** Download a chapter from the series page. Downloads shows a summary card with live progress,
  and each chapter's progress bar fills.
- [ ] **6.4** Home → **Out today** lists series due today.

## 7. Me

- [ ] **7.1** Open Me. **Downloaded only** and **Incognito** are big tiles; turn Incognito on, read a page, check
  History: nothing was recorded. Turn it off again.
- [ ] **7.2** Stats shows the reading heatmap; set a daily goal and see "x of y chapters today".
- [ ] **7.3** Settings → type in the search bar. Matching settings show up as you type.
- [ ] **7.4** Collection: tap an avatar or frame, tap Use; it shows on your profile. Share a sticker into a chat app.
- [ ] **7.5** Settings → Data and storage → Create backup. Restore it on another install; library, categories and
  history come back.

## 8. Edges

- [ ] **8.1** Turn on airplane mode and open a downloaded chapter. It reads normally; music for downloaded episodes
  still plays.
- [ ] **8.2** Rotate the phone during auto-scroll and with a sleep timer running. Both keep going.
- [ ] **8.3** With no sources installed, Home, Library, Updates and History each show a simple icon with one clear next step,
  never a blank screen.

## Telling us how it went

The most useful reports say: the step number, what you expected, what happened, your phone and Android version, and
the app version from Me → About. If the app crashed, the crash screen's **Dump crash logs** button saves a file you can
attach.
