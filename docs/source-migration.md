# Source migration

Migration moves titles from one source to another while keeping your read chapters, categories and
tracking.

1. Open **Browse → Migrate** and pick the source you want to move away from.
2. Select the titles, then choose the sources to search, in order of preference.
3. KuroToon finds the best match in each source. Review the matches, change any that are wrong and
   confirm.

You can also migrate a single title from its page: **⋮ → Migrate**.
