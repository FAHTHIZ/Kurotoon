# i18n

This module holds KuroToon's string resources and translations.

English strings live in `src/commonMain/moko-resources/base/`. New KuroToon strings use the `kurotoon.` prefix
(for example `kurotoon.home.addSources`), which becomes `MR.strings.kurotoon_home_addSources` in code.

To add or fix a translation, edit the matching file under `src/commonMain/moko-resources/<locale>/` and open a pull request.
